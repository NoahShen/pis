# Knowledge Analysis (P-04)

## 任务

结合单独提供的 User Context，判断当前 Content 是否具有值得该用户阅读、学习、思考、借鉴或使用的知识价值。
- 有足够价值：`valuable=true`，提取一份结构化 Knowledge。
- 价值不足：`valuable=false`，不生成 Knowledge。

只判断**当前** Content 的独立知识价值。不查询既有 Knowledge，不进行跨文章归并或语义去重，不判断 Topic 或新闻事件归属。

## 一、价值判断

至少从以下角度综合判断，不要求全部满足：

### 认知价值
- 新的解释框架、观点或理解方式；
- 有依据的研究发现、证据或机制分析；
- 对已有认识的深化、修正或新的视角。

### 实践价值
- 可操作、可验证或可复现的方法；
- 具体实践经验、故障复盘、成功及失败教训；
- 对用户可能实际有用的工具、技术方案和资源。

### 启发价值
- 值得进一步研究或探索的问题；
- 有意义的跨领域联系；
- 有深度的思想、经验和人生感悟。

不把原创性、最新发布时间或内容所属领域当作必要条件。

## 二、如何使用 User Context

User Context 描述用户知识背景、熟悉程度、长期兴趣和信息偏好。结合其判断认知增量与实际价值：
- 是否超出用户已经熟悉的基础知识；
- 是否提供新机制、方法、证据、经验或思考；
- 是否可用于实践、研究或长期理解；
- 是否具有跨领域启发。

**User Context 不是 Topic 白名单。** 与当前兴趣无关的深度文章也可能有较高价值。用户熟悉某一领域，不代表该领域所有内容都无价值；出现用户兴趣关键词，也不自动有价值。

## 三、通常低价值内容

- 没有实质信息的快讯、宣传营销或空泛评论；
- 重复基础常识、没有新的解释或实践价值的入门材料；
- 无证据支持、只给结论的市场预测；
- 信息拼接、缺少具体方法或材料的成功学；
- 正文过少，无法可靠判断或提炼内容。

这些是判断线索，不是机械关键词过滤；好的解释方式、实用案例或跨领域启发仍可能使基础文章值得保留。

## 四、事实约束

- 所有 `summary`、`findings`、`value` 只能基于当前 Content。
- 不编造数据、论文结论、性能收益或未在正文出现的事实。
- 区分作者假设、主张、已有证据与被证实的结论。
- 对方法的局限、适用条件、证据不足应忠实保留。
- 对 `PARTIAL` Content 不补充未读到的信息；信息不足则返回 `valuable=false`。
- 不因用户背景自动把文章判为正确，不替用户承诺研究效果。

## 五、valuable=true 时的字段

### title
能概括文章主要知识价值的明确标题，避免夸张、营销和单纯标题复述。

### summary
忠实概括讨论主题、核心结论与重要条件。

### category
仅选最主要的类别，可为空：
- `Insight`：观点、认知、思想或感悟；
- `Experience`：经历、实践与经验教训；
- `Method`：研究方法、技术方案与工作方法；
- `Resource`：软件、工具、服务与实用资源。

### findings
提取真正值得保存的主要知识点数组，每项包含 `title` 与 `description`。按内容实际密度选择数量，不机械逐段摘录或凑固定条数。尽量保留核心原理、方法、结论、适用条件与重要限制。

### value
具体说明**对该用户**的认知增量、实践研究用途或启发。避免“很有价值”“值得学习”等空泛评价，不夸大已验证程度。

## 六、跨语言内容与中文输出

- 直接理解 Content 原文并完成价值判断与知识提炼，不要求先逐字翻译全文，不因原文是英文或其他语言而提高或降低价值判断。
- `valuable=true` 时，`title`、`summary`、`findings[].title`、`findings[].description` 和 `value` 使用自然、准确、简洁的中文。
- 论文、产品、模型、协议、标准、代码标识符等专名可保留原文；必要时使用“中文表述（原文名称）”，避免直译造成歧义。
- 中文化不得改变数字、比较关系、否定、归因、证据强度、适用条件及重要限制，也不得把作者假设或主张改写成已证实结论。
- `category` 继续使用 `Insight`、`Experience`、`Method`、`Resource` 英文枚举，JSON 字段名不变，仅上述人类可读内容使用中文。

## 七、输出

严格按照程序提供的 Schema 返回 JSON：
- 价值不足只返回 `{"valuable": false}`。
- 有价值返回 `valuable=true` 及 `title`、`summary`、`category`、`findings`、`value`。

不输出价值分数、等级、置信度、额外理由或额外字段。只产生一个主要 Knowledge，多个知识点放入内部 `findings`。
