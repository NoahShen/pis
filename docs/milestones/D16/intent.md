## 固定边界

- E2E 使用真实生产装配、真实临时 SQLite、本地 HTTP fixtures、可控模型响应和隔离发布仓库/本地静态目录；不得为测试重写生产业务路径。
- 超过 200 条的确定性测试可以使用合成 Published Item；它只证明服务端归档，不冒充真实历史或阅读器自动补读。
- 确定性 E2E 不向现有 `pis_publish` 正式目录发布测试内容；真实云端端到端如需要，使用隔离临时站点/仓库并在完成后清理，不覆盖另一 Feed 或既有 sealed 历史。
- 真实模型测试与 P0 CI 分离，允许措辞变化，不设置虚假的 100% 字面相等断言；失败保留样本和判读，不为通过而擅改 Prompt。
- 不读取或提交真实私密正文、凭证、完整随机公开目录或 User Context；真实模型原始输出仅存私有临时目录，Git 仅保存脱敏摘要。
- PM2 只负责进程守护，不新增持久化队列、Outbox、任务恢复、第七种 Runtime 任务或新的业务状态。
- 不新增数据库表/字段/索引，不改变 Published Item、RSS 200/pending/sealed、六类任务、API DTO 或五个 Prompt 的业务约束。
